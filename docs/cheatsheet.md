## 文件与保存

### 用 sudo 权限保存当前文件

```vim
:w !sudo tee % > /dev/null
```

**它到底做了什么**（这条命令不是普通的保存）：

| 片段 | 含义 |
| --- | --- |
| `:w !cmd` | 把**缓冲区内容当成 stdin 喂给 `cmd`**，而不是写文件 |
| `%` | 展开为当前文件的路径 |
| `sudo tee %` | `tee` 以 root 身份把收到的内容写进该路径 |
| `> /dev/null` | 丢掉 `tee` 的回显，否则整个文件会被打印到消息区 |

**三个必须知道的坑：**

1. **Neovim 里 sudo 可能问不了密码。**
   Neovim 官方文档明确写着：`:!` 不支持交互式命令（`:help vim_diff`，
   "`:!` does not support 'interactive' commands. Use `:terminal` instead."）。
   sudo 需要输密码时拿不到终端，会直接失败。
   解决办法：先在任意终端（或 Neovim 里 `:terminal`）跑一次 `sudo -v`
   把凭据缓存住（默认 15 分钟），再回来执行上面这条命令。

2. **执行完缓冲区仍然是「已修改」状态。**
   因为 Neovim 认为自己从没写过这个文件，它只是把内容管道给了别人。
   磁盘上其实已经是新内容了，需要 `:e!` 重新加载让状态同步。
   过程中出现 `W10: Warning: Changing a readonly file` 是正常的。

3. **路径含空格会炸。** `%` 是直接展开的，含空格/特殊字符时改写成 `:w !sudo tee "%" > /dev/null`。

> 更省事的替代方案：一开始就 `sudo -e 文件名`（`sudoedit`），
> 它会用你自己的编辑器编辑一份临时副本，退出时再以 root 写回。

### 撤销历史：跨会话与时间穿越

本配置开了 `undofile`，撤销树持久化在 `~/.local/state/nvim/undo/`
（文件名是把原路径的 `/` 换成 `%`）。所以关掉 Neovim 再打开同一个文件，
`u` 依然能一路退回上次的编辑状态。

注意落盘时机：**撤销树只在 `:w` 保存时写入**。改了一堆但一次都没保存就退出，
不会留下任何 undo 文件，那些改动无法找回。

| 命令 | 作用 |
| --- | --- |
| `u` / `<C-r>` | 撤销 / 重做 |
| `:undolist` | 列出撤销树的所有分支和时间 |
| `g-` / `g+` | 按**时间顺序**在整棵撤销树里前后移动 |
| `:earlier 10m` / `:later 10m` | 回到 10 分钟前 / 前进 10 分钟 |
| `:earlier 3f` / `:later 3f` | 按**保存次数**回退/前进 3 次（`f` = file write） |

`u` 和 `g-` 的区别是关键：`u` 只在当前分支上退；如果你撤销之后又输入了新内容，
就会分叉出一条新分支，之前那条分支用 `u` 再也回不去了——这时候只有 `g-` 或
`:earlier` 能带你回去。

### 崩溃恢复（swap 文件）

本配置开着 `swapfile`。编辑期间未保存的改动会持续写进 `~/.local/state/nvim/swap/`，
断电或进程被杀之后可以捞回来。

```vim
:recover 文件名     " 从 .swp 里恢复未保存的内容
```

```bash
nvim -r 文件名      " 命令行直接进入恢复模式
nvim -r            " 列出所有可恢复的 swap 文件
```

**再次打开该文件时会弹 `E325: ATTENTION`**，提示信息里会写明 swap 文件的
创建时间、进程 ID、`modified: YES/NO`，然后给出六个选项：

```
[O]pen Read-Only, (E)dit anyway, (R)ecover, (D)elete it, (Q)uit, (A)bort:
```

| 选项 | 什么时候用 |
| --- | --- |
| `R` | **崩溃后恢复**：把 swap 里的内容读进来，然后 `:w` 存盘 |
| `D` | swap 是上次崩溃的残留、内容已经不需要了，直接删掉它 |
| `O` | **文件正被另一个 Neovim 打开着**：只读方式看一眼，不会冲突 |
| `Q` / `A` | 拿不准就先退出，去查清楚是哪种情况 |
| `E` | 强行编辑。除非确定另一个实例已经不存在，否则不要选，会互相覆盖 |

判断是哪种情况看提示里的 **process ID**：那个进程还活着，就是「多开」；
已经不存在，就是「上次崩溃的残留」。

选 `R` 恢复之后，swap 文件**不会自动消失**，下次打开还会再弹一次。
确认内容已经 `:w` 存盘后，再打开一次选 `D` 删掉它，
或者直接去 `~/.local/state/nvim/swap/` 手动删。

## 模式切换

### 从终端模式切回 Normal 模式

```
Ctrl-\ Ctrl-n
```

在 `:terminal` 打开的终端缓冲区里，键盘输入默认全部转发给终端程序，
`Esc` 会被当成字符发下去（所以在里面按 Esc 是退不出来的）。
`Ctrl-\ Ctrl-n` 是唯一不会被终端截走的逃生口，按完就回到 Normal 模式，
可以正常滚动、复制、切窗口。

想再回到终端交互，在终端缓冲区里按 `i` 或 `a` 即可。

> 想把它映射成更好按的 `<Esc>`：
> `vim.keymap.set("t", "<Esc>", "<C-\\><C-n>")`。
> 代价是从此在终端里再也发不出真正的 Esc（vim、less、htop 等程序会受影响），
> 所以通常换成 `<Esc><Esc>` 双击，或者干脆保持原样。目前配置里没有加。

⚠ 终端模式（模式名 `t`）下 Neovim **没有任何默认映射**，
`<C-\><C-n>` 不是映射，是写死在按键处理里的。
所以 `:tmap` 输出为空是正常的，不代表「终端里什么都没绑」。

## 内置终端（`:terminal`）

装终端插件之前先知道内核已经给了什么。下面这些**不需要任何插件**。

| 命令 / 按键 | 作用 |
| --- | --- |
| `:terminal` | 在当前窗口开一个跑 `'shell'` 的终端缓冲区 |
| `:terminal {cmd}` | 直接跑某条命令，如 `:terminal make test` |
| `:split \| terminal` | 开在下方分屏里，不占掉正在看的文件 |
| `[[` / `]]` | 在 shell 提示符之间往回 / 往后跳（Normal 模式下） |
| `<C-\><C-n>` | 回到 Normal 模式（见上一节） |

`[[` / `]]` 靠的是 shell 在每个提示符前后发的 OSC 133 转义序列
（`:help terminal-osc133`）。**shell 没配的话这两个键什么都不会发生**——
不是坏了，是没有提示符标记可跳。zsh / bash 需要在自己的 rc 里输出这个序列，
fish 和 kitty、WezTerm 之类的终端模拟器多数已经内置了。

打开终端缓冲区时，Neovim 会自动为它设好一批选项（`:help terminal-config`）：

| 选项 | 值 | 效果 |
| --- | --- | --- |
| `number` / `relativenumber` | `false` | 不显示行号 |
| `signcolumn` / `foldcolumn` | `no` / `0` | 左边不留标记列和折叠列 |
| `wrap` / `list` | `false` | 长输出不折行、不显示不可见字符 |
| `scrollback` | `10000` | 往回能翻一万行输出 |
| `modifiable` | `false` | 缓冲区内容只读（输入是发给程序，不是编辑文本） |

**进程退出后缓冲区不会自己消失**，末尾会多一行 `[Process exited 0]` 的虚拟文本，
需要自己 `:bd!` 关掉。（本配置装的 toggleterm 会替你关，见
[README](../README.md) 的终端一节。）

## 0 插件就已经有的内置功能

Neovim 0.11 / 0.12 把很多以前要装插件才有的能力做进了内核。
在装任何插件之前，先确认这些够不够用（完整列表见 `:help default-mappings`）。

### 注释切换（不需要 Comment.nvim）

| 按键 | 作用 |
| --- | --- |
| `gcc` | 注释/取消注释当前行 |
| `gc{motion}` | 注释一个范围，如 `gcap` 注释整段 |
| `gc`（可视模式） | 注释选中区域 |

### 跳转类（`[` / `]` 系列）

| 按键 | 作用 |
| --- | --- |
| `]d` / `[d` | 下一个 / 上一个诊断（LSP 报错） |
| `]D` / `[D` | 本文件最后一个 / 第一个诊断 |
| `]q` / `[q` | 下一个 / 上一个 quickfix 项 |
| `]b` / `[b` | 下一个 / 上一个缓冲区 |
| `]<Space>` / `[<Space>` | 在当前行下方 / 上方插入空行 |

### diff 模式

两个窗口并排比对同一份内容的差异。进入方式：命令行 `nvim -d 文件A 文件B`，
或者在已经开着的两个窗口里各执行一次 `:diffthis`。
本配置的 `<leader>gd`（gitsigns，和上次提交比）开出来的就是这个模式，
所以下面这些键在那里全都能用。

| 按键 / 命令 | 作用 |
| --- | --- |
| `]c` / `[c` | 跳到下一处 / 上一处差异 |
| `do` | **o**btain：把对面那份的这块内容取过来（等于 `:diffget`） |
| `dp` | **p**ut：把自己这块推过去覆盖对面（等于 `:diffput`） |
| `:diffupdate` | 手动重算差异（编辑之后高亮没跟上时用） |
| `:diffoff` | 退出当前窗口的 diff 模式 |
| `zo` / `zc` / `zr` / `zm` | 展开 / 折起相同的部分（diff 模式会自动折叠没差异的行） |

三个坑：

- **`do` 和 `dp` 只在恰好两个窗口 diff 时能直接用**。三个以上时它不知道该跟谁换，
  要指明对方是谁：`3do` / `:diffget 3`（这个 3 不是「重复三次」，是**缓冲区号**，`:ls` 查）。
- **两个键在可视模式下都不管用**（`:help do` 里明写了 "doesn't work in Visual mode"）。
  想按选区来，用带范围的命令形式：`:'<,'>diffget` / `:'<,'>diffput`。
- **`do` 不是「删除」**。`d` 在这里不是操作符，`do` / `dp` 是两条完整的普通模式命令，
  后面不接动作。

### LSP（无需任何插件，只要配好 language server）

| 按键 | 作用 |
| --- | --- |
| `K` | 悬浮显示文档 |
| `grn` | 重命名符号 |
| `gra` | 代码操作（code action） |
| `grr` | 查找引用 |
| `gri` | 跳到实现 |
| `grt` | 跳到类型定义 |
| `<C-]>` / `<C-t>` | 跳到定义 / 跳回来（走的是 tag 栈，可以一路跳一路退） |
| `<C-s>`（插入模式） | 显示当前函数的参数签名 |
| `gq{motion}` | 按 language server 的规则格式化一个范围 |
| `<C-w>d` | 浮窗显示光标所在行的诊断全文 |

用起来会踩到的几点：

- **浮窗里的内容想滚动 / 想复制**：再按一次 `K`（或 `<C-w>d`）会把光标移进浮窗，
  这时它就是个普通缓冲区，`j` `k` 翻、`y` 复制，`q` 关掉。
- **结果列表分两种，别记混**：
  - `gri` `grt` `<C-]>` 只有一个结果时直接跳过去；多个结果才开 **quickfix**，
    接着 `]q` `[q` 逐个走，`:copen` 重新调出列表。
  - `grr` **不管几个结果都开 quickfix**，因为「只有一处引用」本身就是要看的信息。
  - `gO` 开的是 **location list**（窗口局部的那份），对应 `]l` `[l` 和 `:lopen`。
- **`gra` 在可视模式下作用于选区**：选中几行再按，才拿得到「提取成函数」这类操作。
- **`grn` 改的是符号，不是文本**：它认的是 language server 眼里的「同一个东西」，
  所以字符串和注释里的同名字不会被误改，跨文件的引用则会一起改。
  改完记得看一眼受影响的文件有没有全部保存（`:wa`）。
- **`<C-]>` 依赖 `tagfunc`**：没挂 language server 的文件里它会回退去找 tags 文件，
  一般会报 `E433: No tags file`，那不是配置坏了，是这个文件本来就没有 LSP。

### Treesitter 选区（可视模式）

| 按键 | 作用 |
| --- | --- |
| `an` / `in` | 选中外层 / 内层语法节点 |
| `]n` / `[n` | 选中下一个 / 上一个节点 |

### 其他

| 按键 | 作用 |
| --- | --- |
| `gO` | 打开当前文件的大纲（帮助文档、Markdown、LSP 符号都支持） |
| `gx` | 用系统默认程序打开光标下的路径或 URL |
| `<C-l>` | 清除搜索高亮 + 刷新 diff 高亮 + 重绘屏幕（终端串行乱码时也靠它恢复） |
